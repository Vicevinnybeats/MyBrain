---
description: Build or query a mybrain knowledge graph
---

Invoke the `mybrain` skill immediately.

Pass the full `/mybrain` argument string through unchanged.
If no arguments were supplied, treat the target path as `.`.

Examples:
- `/mybrain`
- `/mybrain src --update`
- `/mybrain query "what connects auth to billing?"`

Do not answer from raw files before handing off to the `mybrain` skill.
